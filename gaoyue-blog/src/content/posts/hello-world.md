这里是高月的博客，一个用来存放代码笔记、阅读摘抄和生活碎念的地方。

## 为什么写博客

信息流刷得越多，越觉得需要一块属于自己的、安静的地方。把零散的想法整理成文字，本身就是一种思考。

> 写作不是为了被看见，而是为了看清自己。

## 这里会写什么

- **技术笔记**：前端、React、工程化，以及踩过的坑
- **阅读记录**：读到的好书与摘抄
- **生活随笔**：旅行、咖啡和一些没什么用的观察

## 技术栈

这个站点用 Vite + React 搭建，文章以 Markdown 文件的形式管理：

```bash
npm install
npm run dev
```

有新想法时，在 `src/content/posts` 里新建一个 `.md` 文件，就完成了一次发布。

欢迎常来坐坐。
